# MapleForge default theme art

Original vector art for the separate MapleForge community site. These files contain no Xform3 artwork, logos, tripods or branding. They contain general Canadian landscape and heritage motifs only.

Palette: spruce `#173D3B`, cedar `#335D50`, maple `#BB553E`, lake `#76ACB5`, warm ivory `#F8F6EF`, lantern gold `#F5D58E`, shield rock `#637D78`.

- `mapleforge-panorama.svg` (1600 × 240): shallow header scene. Use `background-size: cover; background-position: center bottom` behind a compact title row. Keep text on a solid or translucent ivory panel if it overlaps the side illustrations. At narrow widths, crop the edges rather than scaling the header taller.
- `mapleforge-pattern.svg` (320 × 320): very faint repeating texture for outer page margins or quiet side panels. Do not place it under dense text or chat messages.
- `mapleforge-divider.svg` (1200 × 42): low-height divider between existing sections. Crop or scale proportionally.
- `mapleforge-maple.svg`, `mapleforge-canoe.svg`, `mapleforge-beaver.svg`, `mapleforge-lantern.svg` (64 × 64): compact accents. Display at 20 to 32 CSS pixels, beside section labels or topic categories, not every list row. The files have transparent backgrounds and descriptive SVG labels.

Suggested default theme: warm ivory page surface with spruce text, off-white cards, lake-blue focus state, maple-red primary accents, and restrained gold for badges. Keep proposal lists and chat on opaque cards for contrast. Apply this art only to the MapleForge default theme and leave other user-selectable themes unchanged.

No attribution or external image dependencies. All shapes are original SVG paths. No deployment or portal edits are included in this pack.
